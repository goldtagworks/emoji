# 📋 문서용 안전 심볼 표

> **Documentation-safe Symbols & Emoji Reference** — GitHub·Markdown·Notion·Confluence·Slack 어디에서도 깨지지 않고 동일하게 렌더링되는 기호 모음. 클릭 한 번에 복사해서 문서에 바로 붙여넣으세요.

🔗 **Live**: <https://goldtagworks.github.io/emoji/>

---

## 왜 "안전(Safe)"인가

기술 문서·PR 설명·ADR·릴리즈 노트를 쓰다 보면, 화려한 이모지가 **렌더러마다 다르게 보이거나 아예 깨지는** 문제를 자주 만납니다. 이 페이지에 모인 글리프는 다음 기준을 통과한 것들입니다.

- ✅ Unicode BMP 영역 위주 — 거의 모든 시스템 폰트가 지원
- ✅ GitHub Flavored Markdown · Notion · Confluence · Slack · Jira에서 동일 렌더
- ✅ 다크 / 라이트 모드 모두에서 가독성 검증
- ✅ 컬러 이모지 의존 최소 — 흑백 PDF 출력에서도 의미 유지

## 주요 기능

| 기능 | 동작 |
|------|------|
| **클릭 복사** | 카드 클릭 → 클립보드 복사 + 토스트 알림 |
| **멀티 선택** | `Shift+클릭`으로 여러 심볼을 묶어 한 번에 복사 |
| **한글 초성 검색** | `ㅎㅅㅍ` → "화살표", `ㅋㅈㅁ` → "체크 마크" |
| **다중 키워드 검색** | 영문(`arrow`), 한글(`경고`), 별칭(`warn`, `flow`) 동시 매칭 |
| **최근 사용** | 자주 쓰는 심볼이 `localStorage` 기반으로 상단 고정 |
| **자주 쓰는 조합** | `Draft → Review → Done` 같은 상용 패턴 1-click 복사 |
| **커스텀 조합 추가** | 자기 팀 워크플로우에 맞춘 조합을 만들고 저장 |
| **Preset 전환** | `Full` ↔ `Notion/Wiki (Minimal)` — 사용처별 노이즈 제거 |
| **카테고리 필터** | 흐름·상태·경고·구조 등 8개 카테고리 토글 |
| **다크 / 라이트 테마** | 자동 감지 + 수동 토글 (🌙 ↔ ☀) |
| **Unicode 호버** | 마우스 호버 시 `U+2192` 같은 코드포인트 즉시 확인 |

## 카테고리

| 카테고리 | 예시 | 용도 |
|----------|------|------|
| **Core** (문서 필수) | `→ ✓ • —` | 가장 많이 쓰는 기본 글리프 |
| **Arrows** (흐름 / 전환) | `→ ← ↔ ⇒ ▶ ▼` | 워크플로우, 상태 전이, 정렬 표시 |
| **Status** (체크 / 상태) | `✓ ✗ ● ○ ★ ◆ ※` | 완료·실패·중요도·우선순위 |
| **Warnings** (경고 / 주의) | `⚠ ‼ ☐ ☑ ⊕ ⊖` | 주의 표기, 체크박스, 추가/제거 |
| **Structure** (트리 / 구조) | `├ └ │ ─ — – … ·` | 디렉토리 트리, 구분선, 범위, 가운뎃점 |
| **Brackets / Quotes** (괄호 / 인용) | `「」『』〈〉《》` | 한국어 인용, 학술 표기 |
| **Math / Logic** (수학 / 논리) | `≈ ≠ ≤ ≥ ± ∞ ∑` | 수치·논리 기호 |
| **Reference** (참조 / 법률) | `§ ¶ © ® ™` | 절·항 참조, 라이선스 표기 |

## 로컬에서 실행

순수 정적 페이지(`index.html` 단일 파일)라 빌드 도구가 필요 없습니다.

```bash
git clone https://github.com/goldtagworks/emoji.git
cd emoji
open index.html      # macOS — 브라우저로 바로 실행
# 또는 간단한 HTTP 서버
python3 -m http.server 8000
```

`localStorage` 기반의 "최근 사용 / 커스텀 조합"을 검증하려면 `file://` 보다 HTTP 서버 경로를 권장합니다.

## 활용 시나리오

- **PR 설명** — `→` `✓` `⚠` 로 변경 흐름·테스트 결과·주의사항 정리
- **ADR / RFC** — `§` `¶` 으로 절·항 참조, `⇒` 로 결론 화살표
- **릴리즈 노트** — `★` 신기능, `✓` 버그 수정, `⚠` 호환성 주의
- **디렉토리 구조 문서** — `├ └ │ ─` 로 트리 그리기 (코드블록 안에서도 동일 렌더)
- **코드 리뷰 코멘트** — `?` 질문, `!` 가벼운 경고, `‼` 강한 경고
- **체크리스트** — `☐ → ☑` 진행 상태
